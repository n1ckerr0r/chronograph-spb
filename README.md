# chronograph-spb
Цифровой хронограф Санкт-Петербурга на go + js - интерактивная веб-платформа для визуализации истории города через события и локации. Проект позволяет пользователям исследовать историю Петербурга на интерактивной карте с временным слайдером (XVIII-XXI вв.). Упор в проекте сделан на presentation слой.
